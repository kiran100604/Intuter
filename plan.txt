## 3. Database Setup

### Sequelize Configuration (`config/database.js`)
```javascript
const { Sequelize } = require('sequelize');

const sequelize = new Sequelize({
  dialect: 'postgres',
  host: process.env.DB_HOST,
  port: process.env.DB_PORT,
  database: process.env.DB_NAME,
  username: process.env.DB_USER,
  password: process.env.DB_PASSWORD,
  logging: process.env.NODE_ENV === 'development' ? console.log : false,
  pool: {
    max: 10,
    min: 2,
    acquire: 30000,
    idle: 10000
  },
  define: {
    timestamps: true,
    underscored: true,
    freezeTableName: true
  }
});
```

### Model Associations (`models/index.js`)
```javascript
// Define all associations
StudySession.hasMany(Topic, { foreignKey: 'session_id' });
StudySession.hasMany(StudyMaterial, { foreignKey: 'session_id' });
StudySession.hasMany(ConceptMap, { foreignKey: 'session_id' });
StudySession.hasMany(StudySummary, { foreignKey: 'session_id' });
StudySession.hasMany(UserQuestion, { foreignKey: 'session_id' });

Topic.belongsTo(StudySession, { foreignKey: 'session_id' });
Topic.hasMany(Subtopic, { foreignKey: 'topic_id' });

Subtopic.belongsTo(Topic, { foreignKey: 'topic_id' });
Subtopic.hasOne(SubtopicProgress, { foreignKey: 'subtopic_id' });
Subtopic.hasMany(LearningContent, { foreignKey: 'subtopic_id' });
```

## 4. Core Components

### Authentication System
**JWT-based authentication with secure password hashing**

**Flow:**
1. User registers → Hash password with bcrypt
2. User logs in → Verify password, generate JWT
3. Protected routes → Verify JWT in middleware

### Session Management
**Handle study session lifecycle**

**Key Operations:**
- Create session with subject, goal, outline
- Extract text from uploaded outline
- Generate topics/subtopics blueprint
- Track current position in learning path
- Calculate completion percentage

### Content Generation Pipeline
**Multi-step AI content generation**

**Workflow:**
1. User selects subtopic
2. Generate core intuition (if not exists)
3. Build context from previous learning
4. Generate content for current step
5. Extract and store key concepts
6. Update progress
7. Generate summary (background job)

## 6. Services Layer

### AI Services

#### Blueprint Generator (`services/ai/blueprintGenerator.js`)
**Purpose:** Generate topics and subtopics from course outline

**Process:**
1. Take subject name, goal, and outline text
2. Prompt AI to create structured curriculum
3. Parse response into topics with subtopics
4. Save to database with proper ordering
5. Set prerequisites based on dependencies

**AI Prompt Structure:**
```
You are an expert curriculum designer. Based on the following:
- Subject: {subject_name}
- Learning Goal: {goal}
- Course Outline: {outline_text}

Create a structured learning path with:
1. Main topics (5-10 topics)
2. Subtopics under each (3-7 subtopics)
3. Prerequisites for each topic
4. Difficulty level
5. Estimated duration

Return as JSON...
```

#### Content Generator (`services/ai/contentGenerator.js`)
**Purpose:** Generate learning content for intro/understanding/mastering steps

**Process:**
1. Get subtopic and current step
2. Build context (previous learnings, core intuition)
3. Generate content based on step type
4. Extract key concepts from generated content
5. Save content and concepts
6. Update progress

**Context Building:**
- Include core intuition for topic
- Include summaries of completed subtopics
- Include key concepts learned
- Include prerequisite knowledge
- Limit context to most recent/relevant items

**Step-Specific Prompting:**
- **Introduction:** Focus on "what" and "why", build intuition
- **Understanding:** Focus on "how", detailed explanations
- **Mastering:** Focus on application, examples, edge cases

#### Intuition Generator (`services/ai/intuitionGenerator.js`)
**Purpose:** Generate core intuition for a topic (once per topic)

**Process:**
1. Take topic name and description
2. Generate fundamental understanding
3. Create mental model/analogy
4. Save to Topic model
5. Use in all subsequent content generation

#### Summary Generator (`services/ai/summaryGenerator.js`)
**Purpose:** Generate concise summaries for efficient context

**Process:**
1. Triggered when step completed
2. Summarize what was learned in that step
3. Extract key points (3-5 bullet points)
4. Save to StudySummary model
5. Update ContextCache

**Background Job:** Run as async job to not block user

#### Question Answerer (`services/ai/questionAnswerer.js`)
**Purpose:** Answer user questions based on learned content

**Process:**
1. Receive user question
2. Build context from learned topics/concepts
3. Query AI with context + question
4. Store question and answer
5. Track which context was used

### Context Services

#### Context Builder (`services/context/contextBuilder.js`)
**Purpose:** Build optimized context for AI content generation

**Key Functions:**

**`buildContextForContent(sessionId, topicId, subtopicId, step)`**
- Get core intuition for topic
- Get summaries of completed topics
- Get summaries of completed subtopics in current topic
- Get key concepts (limit to top 20 most recent/relevant)
- Format for AI prompt

**`buildContextForQuestion(sessionId, question)`**
- Analyze question to identify relevant topics
- Get summaries of those topics
- Get related concepts
- Limit context size for performance

**Context Prioritization:**
1. Current topic intuition (highest priority)
2. Prerequisite topics summaries
3. Related concepts
4. Recent learnings
5. General session context

#### Context Cache (`services/context/contextCache.js`)
**Purpose:** Cache frequently used context data

**Cached Items:**
- Completed topics list
- All concepts for session
- Topic summaries
- Session statistics

**Cache Strategy:**
- TTL: 30 minutes for most data
- Invalidate on updates (step completion, new content)
- Store in ContextCache model

#### Concept Extractor (`services/context/conceptExtractor.js`)
**Purpose:** Extract key concepts from generated content

**Process:**
1. Take generated content text
2. Prompt AI to extract key concepts
3. Get concept name + brief explanation
4. Classify importance (high/medium/low)
5. Save to ConceptMap model

## 8. AI Integration

### AI Provider Setup

**Claude (Anthropic)**
```javascript
const Anthropic = require('@anthropic-ai/sdk');

const anthropic = new Anthropic({
  apiKey: process.env.ANTHROPIC_API_KEY,
});

async function generateContent(prompt, maxTokens = 4000) {
  const message = await anthropic.messages.create({
    model: 'claude-sonnet-4-20250514',
    max_tokens: maxTokens,
    messages: [
      { role: 'user', content: prompt }
    ],
  });
  
  return message.content[0].text;
}
```

**OpenAI (Alternative)**
```javascript
const OpenAI = require('openai');

const openai = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

async function generateContent(prompt, maxTokens = 4000) {
  const completion = await openai.chat.completions.create({
    model: 'gpt-4-turbo-preview',
    messages: [
      { role: 'user', content: prompt }
    ],
    max_tokens: maxTokens,
  });
  
  return completion.choices[0].message.content;
}
```

## 9. File Handling

### Multer Configuration
```javascript
const multer = require('multer');
const path = require('path');

const storage = multer.diskStorage({
  destination: (req, file, cb) => {
    cb(null, 'uploads/');
  },
  filename: (req, file, cb) => {
    const uniqueName = `${Date.now()}-${Math.random().toString(36).substr(2, 9)}${path.extname(file.originalname)}`;
    cb(null, uniqueName);
  }
});

const fileFilter = (req, file, cb) => {
  const allowedTypes = ['application/pdf', 'application/vnd.openxmlformats-officedocument.wordprocessingml.document', 'image/jpeg', 'image/png'];
  
  if (allowedTypes.includes(file.mimetype)) {
    cb(null, true);
  } else {
    cb(new Error('Invalid file type'), false);
  }
};

const upload = multer({
  storage,
  fileFilter,
  limits: { fileSize: 10 * 1024 * 1024 } // 10MB
});
```

## 10. Context Building System

### Context Flow

**When Generating Content:**
1. **Check Cache** - Look for cached context
2. **Build Context** - If not cached:
   - Get topic core intuition
   - Get completed topics summaries
   - Get completed subtopics in current topic
   - Get top 20 relevant concepts
3. **Format Context** - Structure for AI prompt
4. **Generate Content** - Send to AI
5. **Update Cache** - Store for future use

**Context Size Management:**
- Limit summaries to 200 words each
- Limit concepts to top 20 by recency/relevance
- Prioritize current topic context
- Use compression for long context

**Performance Optimization:**
- Cache context for 30 minutes
- Parallel queries for context building
- Pre-generate summaries in background
- Index frequently queried fields

### Performance Optimization
1. **Database Indexes**
   - Index foreign keys
   - Index frequently queried fields (session_id, user_id)
   - Composite indexes for unique constraints

2. **Caching Strategy**
   - Redis for session data
   - Database-level caching for context
   - HTTP caching headers

3. **API Optimization**
   - Pagination for list endpoints
   - Lazy loading for related data
   - Response compression

4. **Background Jobs**
   - Summary generation
   - Cache cleanup
   - Analytics computation

### Security Measures
1. **Authentication:** JWT with HTTP-only cookies
2. **Password Security:** Bcrypt with salt rounds
3. **Input Validation:** Joi schemas for all inputs
4. **Rate Limiting:** Protect AI endpoints
5. **CORS:** Whitelist frontend domain
6. **Helmet:** Security headers
7. **SQL Injection:** Sequelize parameterized queries
8. **File Upload:** Validate types and sizes

### Monitoring & Logging
1. **Winston Logger:** Structured logging
2. **Error Tracking:** Sentry or similar
3. **Performance Monitoring:** New Relic or DataDog
4. **API Metrics:** Request/response times
5. **AI Usage Tracking:** Token consumption, costs
